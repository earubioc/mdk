PreguntasFAQ

Preguntas frecuentesFrequently asked

¿De verdad es gratis?Is it really free?
Sí. Sin publicidad, sin funciones de pago y sin cuenta. Es de código abierto bajo licencia MIT.Yes. No ads, no paid features, no account. It is open source under the MIT license.
Windows me muestra una advertencia al instalarWindows shows a warning when installing
El instalador aún no está firmado digitalmente, así que SmartScreen puede advertir. Pulsa "Más información" y luego "Ejecutar de todas formas". El código es público y puedes revisarlo en GitHub.The installer is not code-signed yet, so SmartScreen may warn. Click "More info" then "Run anyway". The code is public and you can review it on GitHub.
¿Se actualiza solo?Does it update itself?
La versión instalada sí. La portable no puede reemplazarse a sí misma: descarga la nueva desde Releases.The installed version does. The portable one can't replace itself: download the new one from Releases.
¿Hay versión para Mac o Linux?Is there a Mac or Linux version?
Por ahora solo Windows.Windows only for now.
